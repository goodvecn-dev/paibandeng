# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/lang/zh-CN/).

## [0.1.0] - 2026-08-17

### Added

- Independent `LICENSE` (MIT) for GitHub license detection.
- Project `README.md` covering purpose, usage, architecture, and contribution entry points.
- `.gitignore` for common editor, OS, and dependency noise.
- `CHANGELOG.md` to track release history.
- Document metadata (`description`, Open Graph basics) for shareability and discoverability.
- Keyboard navigation for the theme radiogroup (Arrow / Home / End).
- Explicit localStorage write-failure notification when draft persistence is blocked.

### Changed

- Clarified brand landmark labeling for assistive technologies.

### Notes

- Core Markdown → WeChat rich-text engine remains a single-file offline H5 (`index.html`).
